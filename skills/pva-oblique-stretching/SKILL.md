# PVA 斜拉光学膜工艺主线

## 工艺参数与窗口（初值，需以本组数据条件化）
- 拉伸温度 T：80–140℃（Tg≈70–85℃ 视水含量；低于 Tg+15℃ 取向效率骤降）
- 拉伸比 λ：1.5–8（面积守恒下厚度随 1/λ 量级下降）
- 斜拉角 θ：相对机器方向 15–60°；主轴随 θ 旋转
- 应变率：1–100 s⁻¹；低温高速率时取向效率高但均匀性差
- 定型：120–180℃、10–120 s，锁住取向并降收缩

## 因果主线（种子图谱已含，按证据升级）
λ↑ → f↑（仿射，低温）；T↑ → 松弛↑ → f↓；θ → 主轴旋转（几何）；Xc↑ → Δn↑（晶区贡献）；水含量↑ → Tg↓ → 同温度下 f↓。

## 常见陷阱
- 工程应变 vs 真应变混用（务必声明定义）
- 预热干燥不足：水含量使 Tg 漂移 20℃ 量级，取向数据不可比
- 双折射归一化：膜厚变化必须进入 R=Δn·d 的换算

## 输出约定
工艺-结构判断 → 机理边；工艺窗口经验 → 知识卡（pitfall/method）。
