# 10 — 通用高分子仿真引擎设计（替换斜拉 CAE）

> 状态：已批准（2026-11-20，用户确认方案 A）。
> 本文档是「仿真引擎替换」阶段的唯一 spec 来源；实现 PR 与验收均对照本文。

## 1. 背景与动机

当前 `pm_cae_run` / `pm_cae_coupon` 直连外部斜拉双轴拉伸设备专用引擎（`PM_CAE_ROOT`）。问题：

1. **不通用**——绑定单一设备几何，其他高分子课题无法使用；
2. **不可分发**——依赖用户磁盘上的特定 checkout，桌面产品无法自带；
3. **无链级物理**——只有连续介质整机求解，没有高分子链模拟；
4. **判别能力弱**——coupon 一次一个点，无解析前 screening。

决策（2026-11-20）：移除斜拉引擎集成，替换为**通用高分子仿真引擎**（分层混合，见 §3）。
斜拉引擎本体在用户磁盘保留不动；历史验收文档（09a）不改——它记录当时事实。

## 2. 目标 / 非目标 / 反目标

**目标**
- G-A 解析物性层：高分子物理标准模型（Rouse/WLF/VFT/8-chain/FJC/WLC/Flory-Huggins/Avrami/Fox-Flory/Gordon-Taylor/Vrentas-Duda/仿射取向），numpy/scipy 实现，确定性可真值自测。
- G-B MD 链模拟层：LAMMPS 粗粒化（Kremer-Grest 珠簧）链模拟——平衡熔体（Rg）、`fix deform` 拉伸（取向序参量）、降温扫描（Tg 估计）；二进制缺失时优雅降级。
- G-C 工具化：`pm_sim_*` 工具族接入既有权限矩阵/证据账本/科学门控，仿真证据与实测证据在账本中类型区分。
- G-D 全量替换：`pm_cae_*` 与 `PM_CAE_ROOT` 从产品代码中移除（测试/文案/契约同步）。

**非目标**
- 不做全原子力场（OPLS/PCFF）参数化流水线；不做 LAMMPS 二进制分发/安装器；
- 不做 GPU 依赖；不做相场/有限元连续介质求解器；
- 不在本阶段做 Dockview 前端面板（G007/G008 另行推进）。

**反目标（失败条件）**
- 任何把仿真输出当实测证据的通道出现（必须走 kind=simulation 且门控区分）；
- 为"看起来真实"添加未验证的经验参数拟合而不返回定义与单位。

## 3. 总体架构（方案 A：分层混合）

```
工具层  pm_sim_chain_mechanics / rubber_elasticity / viscoelastic / chain_stats
        / crystallization / flory_huggins / tg_blend / diffusion   (Layer A, 常驻)
        pm_sim_md_run                                              (Layer B, 需 LAMMPS)
桥接层  science.ts runScience（既有 JSON CLI 模式，固定 venv + -I + --）
        lammps.ts deck 生成器/运行器/thermo 解析器（PM_LAMMPS_HOME 或 PATH 探测 lmp）
物理层  science/src/pm_science/{chain_mech,rubber,viscoelastic,chain_stats,
        avrami,flory,tg_blend,diffusion}.py      (Layer A)
        science/src/pm_science/md/*.py            (Layer B: deck 生成 + 解析)
外部    LAMMPS lmp 可执行文件（GPL，外部进程调用，不 vendor 进仓库）
```

与既有系统的闭环（每个解析模块对接一个表征工具，形成"预测 vs 实测"比较环）：

| 仿真模块 | 预测量 | 对接的实测 |
| --- | --- | --- |
| chain_stats 仿射取向 | f(λ) | `pm_hermans_analyze` |
| viscoelastic Rouse/WLF | G(t)、a_T | `pm_model_fit`（KWW/Maxwell） |
| crystallization Avrami | X(t)、t½ | `pm_waxs_analyze`（结晶度时序） |
| chain_stats / MD 熔体 | Rg | `pm_saxs_analyze`（Guinier Rg） |
| flory_huggins | 相容性 χ | `pm_literature_extract`（共混文献） |
| tg_blend Gordon-Taylor | Tg(共混) | 文献/DSC 证据 |
| rubber_elasticity | W(λx,λy) 应变能 | 判别实验设计（接替 coupon 角色） |

## 4. Layer A 物理模型与真值自测

全部模块：公共函数带类型标注与 docstring（AGENT.md §3）；返回 `definitions` 字段说明每个量的定义与单位（延续 ftir 模式）。

| 模块 | 模型（标准方程） | 自测真值（selftest 断言） |
| --- | --- | --- |
| chain_mech | FJC：x/Nb = coth(fb/kBT)−kBT/fb（精确）；WLC：Marko-Siggia f=(kBT/p)[1/(4(1−x/Lc)²)−1/4+x/Lc]，力→伸长用二分反演 | FJC f=kBT/b (y=1)：x/Nb=coth(1)−1=0.31304；WLC x/L=0.5, p=1nm, T=300K：f=5.177 pN |
| rubber | 8-chain（Arruda-Boyce）：λc=√(I₁/3)、β=L⁻¹(λc/√N)（精确二分反演 Langevin）、σ=μ√N β/(3λc)·(λ²−λ⁻¹)、P=σ/λ、W=∫P dλ（Simpson）；neo-Hookean 极限 σ=μ(λ²−λ⁻¹)；双轴 λz=1/(λxλy) | N=10⁶ 时 P/W 收敛到 NH 极限（<0.5%）；NH W(λ=2, μ=1)=1.0；W 随 λ 单调增 |
| viscoelastic | Rouse：τ₁=ζb²N²/(3π²kBT)、τp=τ₁/p²、G(t)=(νkBT/N)Σexp(−p²t/τ₁)、G'(ω)/G''(ω) 闭式；WLF：log₁₀a_T=−C₁(T−T₀)/(C₂+T−T₀)；VFT：log₁₀a_T=C/(T−T∞)−C/(T₀−T∞) | G(0)=νkBT 精确；τp=τ₁/p² 精确；WLF 普适常数 T=Tg+10 → a_T=10^(−174.4/61.6)=1.4748e−3（<1%） |
| chain_stats | 理想链 Rg²=Nb²/6、⟨R²⟩=Nb²；仿射取向 ⟨cos²θx⟩=λx²/(Σλᵢ²)、f=(3⟨cos²θ⟩−1)/2 | λ=2 单轴：f=0.70（精确）；Rg²=Nb²/6 精确 |
| avrami | X(t)=1−exp(−Ktⁿ)：ln(−ln(1−X)) vs ln t 线性回归 → (n,K)；t½=(ln2/K)^(1/n) | 合成 n=3, K=1e−3 无噪 → n、K 精确回收 |
| flory | g(φ)=φlnφ/N₁+(1−φ)ln(1−φ)/N₂+χφ(1−φ)；旋节线 χ_s(φ)=½(1/(N₁φ)+1/(N₂(1−φ)))；临界 φc=√N₂/(√N₁+√N₂)、χc=½(1/(N₁φc)+1/(N₂(1−φc)))；可选 χ=A/T+B → Tc | N₁=N₂=100 → φc=0.5、χc=0.02（精确）；χ=0.01<χc → STABLE |
| tg_blend | Fox-Flory Tg=Tg∞−K/M（1/M 线性回归）；Gordon-Taylor Tg=(w₁Tg₁+kw₂Tg₂)/(w₁+kw₂) | FF 合成精确回收；GT w=0.5/0.5, Tg=350/450, k=1 → 400 |
| diffusion | Arrhenius D=D₀exp(−Ea/RT)（lnD vs 1/T 回归）；Vrentas-Duda 自由体积：Vfh/γ=K₁₁ω₁(K₂₁/T−T_g1+1)+K₁₂ω₂(K₂₂/T−T_g2+1)、D₁=D₀exp(−E/RT)·exp(−ω₁V₁*/(Vfh/γ)) | Arrhenius Ea=40 kJ/mol 精确回收；V-D 自由体积因子退化为常数时退回 Arrhenius |

MD 层（Layer B）输出与解析层互校点：Rg(MD 熔体) vs Rg(理想链)（CG 链含排除体积，Rg 略大，作为上下界比较）；取向序参量(MD fix deform) vs chain_stats 仿射 f；Tg(降温扫描密度拐点) vs WLF/VFT 参考温度。**MD 结果标记 `kind=simulation, engine=lammps`，不与实测混比**。

## 7. 证据与门控集成

1. 仿真证据沿用 `sourceRef type:'run'`，payload 增加 `simulation` 块（engine/model/params 摘要）——账本 schema 不变，`verify` 链不受影响。
2. 新增一致性门控 `sim-vs-measurement`：同一项目内存在同一物理量的仿真预测与实测证据时，`pm_gate_check` 比较相对偏差；超阈值（默认 30%）→ `warn`，缺失实测 → `note`（不是错误）。延续"Δn 拒绝当实测"的纪律并制度化。
3. 假设判别模式：预期方向由仿真预测给出（如 affine f(λ)=0.70），实测/表征证据判 supported/refuted——四要素 testDesign 不变。

## 10. LAMMPS 依赖策略

- 运行时解析顺序：`PM_LAMMPS_HOME`（bin/lmp.exe）→ PATH 探测 `lmp`/`lmp.exe`/`lammps.exe` → 未找到 = Layer B 不可用（`overview.sim.md=false`，工具返回 `SIM_UNAVAILABLE` 与安装提示）。解析失败不阻塞 Layer A。
- GPL 合规：外部进程调用 + 用户自行安装（Windows 官方安装器），仓库不 vendor、不静态链接。
- deck 生成：珠簧模型（Kremer-Grest）固定模板 + JSON 参数注入；单位 LJ；时间步 0.005τ；每作业输出 thermo + fix orient/order。

## 11. 风险与诚实边界

1. **CG-MD 时间尺度**：可达 µs，不对应真实 PVA 秒级松弛；MD 输出一律标注时间尺度上下文，不进秒级松弛结论。
2. **粗粒化无化学特异性**：CG 链不区分 PVA/PVA 羟基细节——化学特异性问题（氢键、水解）由 Layer A 模型 + 文献证据承担，MD 只回答链统计/取向普适行为。
3. **解析层是模型方程不是"测量"**：输出全部带模型参数与定义；与实测比较必须经门控，不得直接宣称"验证了"。
4. **MD 缺席场景**：无 LAMMPS 时 chain-level 证据完全缺失，overview 如实报 `md:false`。
