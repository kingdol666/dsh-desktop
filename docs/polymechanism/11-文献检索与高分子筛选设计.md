## 1. 外部插件能力矩阵(2026-11-20 npm registry + GitHub 实测)

### 1.1 dsh-kb-rag@1.6.8(npm,MIT,清华维护者)

- 工具(10):`kb_ingest / kb_status / kb_zotero / kb_search / kb_rag / kb_scope / kb_dedup / kb_clear / kb_stats / kb_fetch`
- **本地知识库**:PDF/TXT/MD/DOCX 入库(PDF 需文本层),BM25(含 CJK bigram)+ 向量(bge-small-zh-v1.5)+ 重排(bge-reranker-base),SQLite 单文件;检索返回段落级标题/作者/年份/期刊/DOI/页码
- **`kb_fetch`:按 DOI/arXiv ID 下载 PDF,"publisher version first, open-access fallback"**,Unpaywall 兜底(`UNPAYWALL_EMAIL`);出版商把自动化请求重定向到登录页时回退"手动下载 + kb_ingest"
- **无在线检索**:不能按主题词搜索全网,只能检索已入库内容
- `kb_zotero`:单向迁移本地 Zotero 库(含 PDF 附件)进知识库,dry_run 支持;不联网下载
- 依赖:Python + sentence-transformers;模型约 1.2GB 首次搜索时下载(`HF_ENDPOINT=https://hf-mirror.com` 预案);`KB_AUTO_PIP=1` 自动补包
- npm peer:`@deepseek-ai/dsh-tools >=0.2.0-rc.2 <0.3.0`(**0.2.1-rc.3 在范围内 ✓**,1.6.8 修复版);client inject:`dsh-client-ui-conversation` + `dsh-client-ui-primitives`(1.6.8 修复版声称适配 DSH 0.2,L1 安装时实测门禁)

### 1.2 dsh-zotero-skill@0.5.5(npm,MIT)

- **在线检索:OpenAlex(主)/ Crossref(可选)**,加权排序 = 期刊影响力 0.45 + 引用速度 0.30 + 相关度 0.15 + 新鲜度 0.10(**通用排序,非高分子专用**)
- 核心筛选:核心/重要/参考三档;watch 增量追新;每日自动收录(Windows 计划任务);引用追踪(一跳参考/被引)
- 中文:知网检索链接生成 + RefWorks/EndNote 导出文件入库(中文条目保留卷期页)
- Zotero:**官方本地 API `127.0.0.1:23119`**,不直接读写 zotero.sqlite;需在 Zotero 设置开启"允许其他应用通信";写操作首次弹窗授权(Always Allow 持久化);全文精读需配套 dsh-reader.xpi
- **收录只导题录与摘要,不自动下载 PDF**(与 kb-rag 的 kb_fetch 互补)
- 依赖:Python 3.10+(基础功能纯标准库);全文精读需 Node 20+,自备私有 Python 3.12/PDF/OCR/字体(首次联网下载 SHA256 锁定)
- npm manifest 无 `@deepseek-ai/*` peer 声明 → 兼容性门禁按"无 peer 要求"通过(1.6.x 门禁规则,安装时实测)

### 1.3 能力缺口 → 本设计补齐项

| 用户需求 | 插件能覆盖? | 缺口 → 自建 |
| --- | --- | --- |
| 在线文献检索 | 部分(zotero-skill 的 OpenAlex/Crossref) | **pm_literature_search**:多源检索 + 高分子筛选一体输出 |
| 非开放期刊下载 | 部分(kb_fetch 单 DOI,出版商反爬即失败) | **pm_literature_download**:OA 链优先 → 出版商直连模板 → 状态分类 + 手动兜底直链 |

| 自动加入 Zotero | 部分(题录+摘要,无 PDF) | Zotero 收录编排 + **附件挂载 spike**(契约测试先行) |
| 自动加入知识库 | 有(kb_ingest) | agent 编排(下载→ingest→证据) |
| 高分子最佳筛选 | 无 | **pm_literature_screen**:期刊分层+词库+topic 匹配+质量分 rubric,Agent 终审 |

## 2. 目标架构与数据流

```
                    ┌─ L1 插件层(装到 desktop profile)──────────────┐
                    │  dsh-kb-rag(kb_* 工具,本地 KB+Zotero 迁移)      │
                    │  dsh-zotero-skill(skill 命令,OpenAlex 检索+库管理)│
                    └──────────────┬──────────────────────────────┘
                                   │ agent 直接调用
┌─ L2 pm 文献工具族(plugins/pm-research,本设计新增)────────────────┐
│ pm_literature_search → OpenAlex+Crossref 检索 → pm_literature_screen │
│ pm_literature_screen → 高分子 rubric 评分 → 判级(core/important/ref) │
│ pm_literature_download → OA链→出版商直连→PDF 落盘+manifest 台账      │
└──────────────┬───────────────────────────────────────────────────┘
               │ 下载成功后 agent 编排(复用既有能力,零新代码)
               ▼
  ① kb_ingest(全文进知识库)  ② zotero-skill 收录(题录+附件)
  ③ pm_literature_read(精读) → ④ pm_literature_extract(claims→证据账本)
  ⑤ pm_knowledge_propose(reviewer approve → 机理图谱 established 边要求 DOI+strong supports)
```

设计原则(与 pm 既有哲学一致):**工具保持确定性/可测试,判断力放在 Agent**——screen 只输出透明 rubric 分数与理由,最终取舍由文献专家(preset persona + skill 规范)基于摘要做出。

## 4. L2:pm 文献工具族设计(新增于 plugins/pm-research)

### 4.1 `pm_literature_search`

- 参数:`query`(必填,英文检索词,agent 负责查询扩展)、`yearFrom`/`yearTo`、`maxResults`(默认 20,≤50)、`sources`(enum 数组,默认 `['openalex']`,可选 `crossref`)、`screen`(boolean,默认 true——结果直接过 §5 rubric)、`preset`/`actor`
- 数据源:**OpenAlex 主源**(免键、works/topics/cited_by_count/OA 位置齐全;`mailto=` 礼貌池)、Crossref 辅源(元数据补全)
- 返回:`{ok,data:{candidates:[{doi,title,venue,year,authors,citedByCount,oaStatus,oaUrl?,topics[],screen:{total,breakdown,grade,reasons[]}}],sources:{openalex:{hits},crossref:{hits}}}}`
- 实现:HTTP 客户端放 Python 侧(`pm_science/litsearch.py`,requests 已在 science venv 依赖域内,新增 requests/httpx 依赖),TS 侧经 runScience 桥(复用既有模式);**Host 侧零新增网络代码,SSRF 守卫落在 Python**(§4.4)

### 4.2 `pm_literature_download`

- 参数:`doi`(必填)、`projectId`(可选,入 manifest 到项目)、`targetPath`(可选,workspace 围栏,默认 `{workspace}/literature/`)、`overwrite`、`preset`/`actor`
- 下载链(依序,成功即停):
  1. **OA 解析**:Unpaywall 全部 `oa_locations` + OpenAlex 全部 `locations`(不仅 best)+ Europe PMC DOI 检索 → PMC 自动转 `europepmc.org/articles/{PMCID}?pdf=render`;仓库副本(White Rose/Zenodo 等)与出版商 OA 都尝试
  2. **传输自适应**:API/OA 仓库默认走系统代理(`HTTPS_PROXY`,Europe PMC 等常只能经代理),失败回退直连;出版商模板/落地页**优先直连**(保留校园 IP 授权),失败再走代理;同一候选在两种传输都成功时保留字节数更大的 PDF(部分 J-STAGE 边缘直连只给预览、代理给全文)
  3. **出版商直连**(campus IP 授权;模板表 config 驱动,可扩展):Springer `link.springer.com/content/pdf/{doi}.pdf`、Wiley `onlinelibrary.wiley.com/doi/pdfdirect/{doi}`、ACS `pubs.acs.org/doi/pdf/{doi}`、RSC/T&F/IOP 走 Crossref `link` 字段的 `application/pdf` href、Elsevier 预期高失败率(SD 反爬)→ 直接给直链走 MANUAL_REQUIRED
  4. **失败分类返回**(不抛异常,状态化):`DOWNLOADED` / `OA_LINK_ONLY`(有 OA 链但网络失败)/ `CAMPUS_REQUIRED`(出版商 401/403/登录重定向——离开校园网/VPN 时预期)/ `CLOUDFLARE_CHALLENGE`(响应头 `Cf-Mitigated: challenge`,不是付费墙;需真实浏览器在校园网/CARSI 下过一次 Turnstile,或改用 OA 仓库副本)/ `MANUAL_REQUIRED`(附 landing + PDF 直链,用户浏览器下载后 `kb_ingest` 或重跑 download 指向本地文件)
- Zotero 落点:PDF 下载后可用 `scripts/literature-to-zotero.mjs` 经 Zotero Connector(`POST /connector/saveItems` + `/connector/saveAttachment`)建条目并挂全文,不使用本地 API key
- 校验:Content-Type `application/pdf` + `%PDF` magic 头 + 大小 ≤50MB + 超时 60s/域名限速 1 req/s 退避
- 落盘命名:`{year}_{firstAuthor}_{shortTitle}_{doi后缀}.pdf`(消毒 `[^A-Za-z0-9._-]`);**manifest**:`{workspace}/literature/literature-manifest.jsonl` append 一行 `{doi,title,venue,year,file,obtainedVia,status,score?,zotero?:{itemKey,attachmentAdded},ingestedKb?:bool,downloadedAt}`;重复 DOI 按 manifest 幂等(已存在返回 existing)
- 参数 `sourceFile`(可选):直接登记用户手动下载的 PDF(manual 兜底入库口)

### 4.3 `pm_literature_screen`

- 独立可复用:输入候选数组(来自 search 或用户手贴的 DOI/title 列表),输出 §5 rubric 评分——支持对已有 manifest/文献列表补筛

### 4.4 安全守卫(Python 侧强制,Mimosa 约束对齐)

- 仅 http/https;请求前 host 校验:拒绝 IP literal 的私有/环回/保留段(RFC1918/RFC4193/127/8/169.254/16/0/8/100.64/10/链路本地等),域名解析结果逐 IP 复查,**重定向每跳重验**

- Zotero 本地 API(127.0.0.1:23119)**不由本设计生成的代码访问**——全部经 dsh-zotero-skill 第三方插件完成,规避生成代码的 loopback 请求约束

## 5. L3:高分子领域"最佳判断"设计

### 5.1 两级筛选

1. **工具预筛(rubric,确定性)**:0-100 分,透明分项
2. **Agent 终审(context 判断)**:文献专家读摘要做 accept/review/reject + 一句理由;skill(`literature-review` 扩章)规定终审协议——是否高分子机理研究、是否落在课题"材料-工艺-结构-性能"链条、测量数据可信度初判

### 5.2 rubric v1(权重进配置文件,可校准)

| 维度 | 权重 | 评分规则 |
| --- | --- | --- |
| 期刊层级 | 35 | Tier A(高分子旗舰)=35;Tier B(领域主流)=25;Tier C(一般 SCI/中文核心)=12;其余=5;跨域顶刊(Nat. Mater./Nat. Commun./JACS/Angew)=30 |
| 主题相关性 | 40 | OpenAlex topic 匹配基础分(polymer science/materials science 系)+ 词库命中:核心词(polymer/PVA/crystallinity/biaxial/orientation/WAXS/FTIR/Tg/film/membrane…)每命中+4 封顶 30,扩展词(+2 封顶 10);标题命中双倍计 |
| 质量信号 | 15 | cited_by_count 对数分 + 新鲜度(近 5 年不衰减,线性衰减至 15 年) |
| 可得性 | 10 | OA 直下=10;出版商直连可试(campus)=6;仅题录=2 |

判级:**core 核心 ≥70 / important 重要 45-69 / reference 参考 <45**(阈值进配置)。

### 5.3 期刊分层初始表(节选,完整表进配置文件)

- **Tier A**:Macromolecules、Progress in Polymer Science、Polymer、ACS Macro Letters、Macromolecular Rapid Communications、Biomacromolecules、Journal of Membrane Science(膜方向)
- **Tier B**:European Polymer Journal、Polymer International、Journal of Applied Polymer Science、ACS Applied Polymer Materials、Polymer Chemistry、Journal of Polymer Science、Soft Matter、Carbohydrate Polymers、Composites Science and Technology、Polymer Degradation and Stability、Materials & Design
- **Tier C**:Polymers(MDPI)、RSC Advances、Polymer Bulletin、Journal of Polymer Research、e-Polymers、高分子学报、高分子材料科学与工程

### 5.4 校准(L03 验收)

以用户课题(PVA 光学膜/双轴拉伸/取向-双折射)已知约 30-50 篇文献为锚集,验证 precision@10 ≥ 0.7、课题核心文献落 core 级;不达标调权重/词库并记录于配置文件注释。可选支持 Scopus/WoS API key(config 占位,无 key 不阻塞)。

## 6. L4:端到端闭环验收

真实场景(在 `D:/pm-acceptance` 或新工作区,校园网连接状态):

1. `pm_literature_search` query="biaxial stretching PVA optical film birefringence" → 得分候选列表
2. 取 1 篇 OA + 1 篇付费(Springer/ACS 类,campus IP)→ `pm_literature_download` 落盘指定目录 + manifest 记录
3. `kb_ingest` 两篇 PDF → `kb_search` 命中验证(知识库)
4. zotero-skill 收录两篇到 Zotero(**含 PDF 附件挂载 spike 结论**;spike 失败则降级"题录+PDF 同目录 RIS"人工一步导入,如实记录)
5. `pm_literature_read` → `pm_literature_extract` ≥3 条 claims → 证据账本(hash 链校验通过)
6. `pm_knowledge_propose` 一张知识卡 → reviewer approve 流转
