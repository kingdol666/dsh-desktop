## 2. 后续 UI 扩展的四级模型

### 级别 1：品牌与文案（本层已基本完成）

改 `product-identity.ts` + 各 `*-copy.ts` / `*-locales.ts`。文案全部双语（zh/en）定义在 copy 模块，不要在组件里散落硬编码。

### 级别 2：布局骨架（改 `src/client/`）

| 想改什么 | 改哪里 |
| --- | --- |
| 三栏比例、折叠行为、窄视口策略 | `layout-state.ts`（`SIDEBAR_DEFAULT`、`SIDEBAR_AUTO_COLLAPSE`、`RIGHTBAR_DEFAULT_RATIO`、`computeDesktopColumns`） |
| 布局结构（加第四栏、顶部工具带） | `AdvancedFrame.tsx`（grid 定义）+ `advanced-shell.ts`（slot children 声明处加 slot）+ `styles.ts`（Desktop-owned 样式） |
| 标题栏按钮/菜单 | `DesktopFrameTitlebarView.tsx`（`MODE_OPTIONS`、`DesktopNativeActions`） |
| 壳层配色/材质 | `theme-presenter.ts`、`extended-styles.ts`、`window-material.ts` |

### 级别 3：科研业务面板（推荐主战场——Cordis UI slots）

不动 `AdvancedFrame` 的通用骨架，为每个科研域写**独立 client 插件**（或 Desktop client 内新模块）注册进插槽：

```ts
// 例：在 sidebar 注册"科研项目"导航、在 rightbar 注册"机理图谱"
ctx.slots.register({ name: 'sidebar', … }, ResearchProjectNav)
ctx.slots.register({ name: 'main',    … }, MechanismGraphCanvas, { key: 'mechanism' })
ctx.slots.register({ name: 'rightbar',… }, EvidencePanel)
ctx.slots.register({ name: 'shell.overlay', … }, GlobalCommandPalette)
```

规划中的页面→插槽映射（与执行计划 Phase 2/3 对应）：

| 页面 | 插槽/宿主 | 数据来源 |
| --- | --- | --- |
| Research Workspace（项目总览） | sidebar + main 新 panel | `research-manager` Host 服务 |
| AI Scientist（专家会话） | main（上游 conversation occupant 复用） | DSH session runtime |
| Mechanism（机理图谱） | main panel / rightbar | `mechanism-graph` 服务 + React Flow |
| Hypothesis（假设看板） | rightbar | `hypothesis-manager` 服务 |
| Characterization（SAXS/WAXS/FTIR） | main panel + Plotly | Science MCP（Python） |
| Physics Lab（模型注册表） | main panel | `model-registry` 服务 |
| Literature / Reports | main panel | 文献服务 / 报告生成器 |

### 级别 4：原生小窗（`src/native-ui/`）

深模态、涉密确认、系统级交互放独立沙箱 BrowserWindow（现有范式：`DesktopDialogWindow` + 独立 Vite 入口 + shadcn）。适合：实验数据导入向导、高风险操作确认（如"覆盖机理结论"）、HPC 任务提交单。

## 3. 改版工作流约定

1. 跟随上游仓库规则：源码改动走 Beta → Stable 镜像（fork 阶段可暂只做 Stable，Beta 待办见执行计划 Phase 0.3）。
2. 每次改动跑 `corepack yarn test`（unit）与 `corepack yarn typecheck`；发布前 `corepack yarn check`。
3. 新增文案必须 zh/en 双语成对；新增测试断言引用新品牌串。
4. 验证 UI 实际效果：`git submodule update --init --recursive` + `corepack yarn install --immutable` + `corepack yarn dev`（需要先初始化上游子模块，首次较慢）。
