# 验收：机理分析专家模式盲测（真实论文数据，2026-11-27）

## 1. 目的与盲测协议

验证机理研究能力能否**仅凭论文实验数据**独立推出机理，再与论文结论对照。

协议：
1. 先只获取数据表（Zenodo 数据包 DOI `10.5281/zenodo.14417456`），阅读其数据说明确认列含义；
2. **不读论文正文的分析与结论**，只用聚合物光氧化物理常识构造候选机理；
3. 用 `pm_mechanism_screen`（science CLI 同一引擎）做量化筛选；
4. 记录盲筛结果后，才查阅论文（PLOS One 2026，DOI `10.1371/journal.pone.0344790`）对照。

数据：`ESR06_11.csv`（羰基指数）、`ESR06_12/13.csv`（接触角，UV / UV+磨损）、
`ESR06_15.csv`（粗糙度）。取 ML2W（白色地膜）构建 tidy 表：
10 个 UV 时间（0–80 d）× 2 种磨损状态 × 接触角均值/SD（27 个测点）、粗糙度、羰基指数均值/SD（3 条光谱）。
文件：`D:/pm-acceptance/pva-oblique-2026-11-20/data/mechanism_pe_ml2w_blind.csv`（20 行）。

## 3. 与论文结论对照

| 问题 | 盲筛（数据） | 论文结论 | 一致性 |
|---|---|---|---|
| UV 是否驱动表面氧化/润湿性 | UV 组接触角指数衰减 R²=0.951（快速下降后平台） | 接触角 21 天内快速下降后趋平台，指数拟合 r²≥0.58；润湿性是敏感早期指标 | ✔ 一致（本数据拟合更好） |
| 磨损的作用 | 磨损主效应 +23.5°，磨损组无确立的时间趋势（R²=0.33） | 磨损组接触角保持接近原始值，无显著时间趋势；归因于去除氧化外层 | ✔ 一致 |
| 粗糙度是否主导接触角 | Wenzel 模型方向相反、拟合更差；粗糙度变化小 | 形貌不是接触角主因；CA 恢复归因于氧化层去除 | ✔ 一致 |
| 羰基指数能否作为机理证据 | 无机理达标（最好 R²=0.22） | 羰基指数多数低于 ATR 检出，UV 时间无显著变化 | ✔ 一致 |
| UV 与磨损是否协同加速 | 接触角交互项 ΔR²≈0.001，无可检出协同 | 论文提出"氧化—磨除—暴露新鲜层"循环，磨损是降解加速器 | ✖ 不矛盾但数据无法检验：横截面 CA 数据只能证明"氧化层被去除"，不能证明长期循环加速（需颗粒生成/多轮磨损实验） |

## 4. 结论

1. 机理专家模式在**未见论文分析**的条件下，从数据独立得到与论文一致的核心机理：
   UV 光氧化导致表面亲水化（指数动力学），磨损去除氧化层使表面保持疏水；粗糙度非主因；羰基指数不敏感。
2. 引擎对数据质量保持了诚实：0.70 阈值下无"全解释"机理，明确列出样本量与过拟合风险；
   羰基通道直接判定不可判别，未硬凑结论——符合"数据不全要问、不编造"的协议。
3. 唯一未验证的是论文的"循环加速"主张；这是实验设计维度（需要多轮磨损/颗粒计数）而非算法能力问题，
   引擎已通过交互项检验给出"当前数据无可检出协同"的边界结论。
