> 已定决策（用户 taste & judge）：混合知识网络（复用记忆插件 + 自研机理图谱）· 文献用 `dsh-kb-rag` + `dsh-zotero-skill` · 科学计算 CAE + 表征分析 · 前端**一步到位 Dockview 工作台**。

## 5. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
| --- | --- | --- | --- |
| 第三方插件注入 client-runtime 无法加载 | 高 | M0 阻塞 | 冒烟先行；备选 `dsh-library`/`dsh-mnemon`；自研禁用该 inject |
| kb-rag Python 模型下载失败 | 中 | 文献检索不可用 | `HF_ENDPOINT` 镜像；降级 `dsh-library` |
| `dockview` 与 React 版本冲突 | 中 | M3 阻塞 | 降级自研三列 + `ResizeHandle`（已验证可复用） |
| CAE 引擎无法 JSON 化输出 | 中 | S2.8 阻塞 | 加 `--json` 开关（只加输出，不改物理）；或解析现有结果文件 |
| 图谱规模增长导致内存索引变慢 | 低 | 性能 | 阈值触发切 `dsh-storage-sqlite` |
| 上游升级破坏 preset/skill 契约 | 中 | 长期 | 锁定版本；契约测试覆盖；不依赖内部类型 |
| 研究结论被质疑"AI 编造" | 中 | 学术风险 | Gate + 证据链 + reviewer + 人类审批；报告强制引用 evidenceId |

## 6. 首个真实案例（贯穿验收）

**PVA 斜拉薄膜的取向—双折射机理判别**（复用你既有 CAE 工程）

1. 建项目：`question = "斜拉角与拉伸比对双折射主轴与幅值的相对贡献"`；
2. 文献：检索 3~5 篇斜拉/双轴 PVA 光学膜文献 → 抽取候选证据；
3. CAE：在 3 组斜拉角 × 3 组拉伸比下运行 → 登记证据；
4. 机理：从种子图谱检索"斜拉角→取向主轴""拉伸比→取向→双折射"路径 → 提候选边；
5. 假设：H1 斜拉角主导主轴旋转；H2 拉伸比主导幅值；设计判别观测（主轴角 vs 幅值的敏感性）；
6. 判别：用 CAE 结果计算敏感度 → 一胜一负 → Gate 审查 → reviewer 出 objection → 人类批准；
7. 沉淀：把"斜拉角主要影响主轴方向而非幅值（在给定条件范围）"写为知识卡（approved，带条件与证据）；
8. 报告：导出证据包（证据 8 条 + 图 4 张 + 参数表 + 审查记录）。

> 该案例同时是**论文素材**与**回归验收用例**（`examples/pva-oblique-birefringence/`）。
